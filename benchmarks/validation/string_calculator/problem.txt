Implement a function `calculate(expression: str) -> float` that evaluates an infix arithmetic expression string containing:
- Integer and float operands
- Operators: +, -, *, /
- Parentheses for grouping
- Spaces (ignore them)

Raise `ValueError` if the expression is invalid or division by zero occurs.

Examples:
- calculate('2 + 3') == 5.0
- calculate('10 / 2 * 3') == 15.0
- calculate('(1 + 2) * (3 + 4)') == 21.0
- calculate('3.14 * 2') == 6.28
